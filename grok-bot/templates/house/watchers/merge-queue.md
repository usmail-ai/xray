# Merge queue

The lab tester's merge watcher appends one line per merge. Tick `[x] PASS` or `[!] FAIL` with one plain note.

Line format from [opproc-cadence.md](https://github.com/0xRayAI/xray/blob/main/docs/opproc-cadence.md) §4:

```
- [ ] <repo> #<PR> <merge sha> fixes #<issue> — <title> — retest: <what to check>
```
